# First Hohenberg-Kohn Theorem
> 多電子系統的基態密度和 external potential 之間存在一對一的對應（Hohenberg 與 Kohn，1964）〔first Hohenberg-Kohn theorem〕

flow: $\hat V_{ext}$ -> $\Psi$（基態） -> $\rho$（基態密度）〔first Hohenberg-Kohn theorem〕

- 映射 $C:\hat V_{ext}\mapsto\Psi$ 與 $D:\Psi\mapsto\rho$ 都是 bijective；$D$ 是 injective 是「非常意外」的部分〔first Hohenberg-Kohn theorem〕
- 推論：任何可觀測的基態性質都能寫成密度的唯一泛函 $\text{property}=\langle\Psi|\hat O|\Psi\rangle=O[\rho]$〔first Hohenberg-Kohn theorem〕
- $\Psi$ 有 $3N$ 個變數，$\rho$ 只有 3 個，但基態密度含有的資訊和基態波函數一樣多〔first Hohenberg-Kohn theorem〕
- 限制：證明針對 non-degenerate ground states；定理只說泛函存在而且唯一，沒有給出形式；只適用於基態〔first Hohenberg-Kohn theorem〕
