# First Hohenberg-Kohn Theorem
> 基態密度和 external potential 一對一對應（Hohenberg 與 Kohn，1964）〔first Hohenberg-Kohn theorem〕

flow: $\hat V_{ext}$ <-> $\Psi$（基態） <-> *$\rho$（基態密度）〔first Hohenberg-Kohn theorem〕

grid: 推論 :: 任何基態性質都是密度的唯一泛函 $O[\rho]$ | 資訊量 :: $\Psi$ 有 $3N$ 個變數，$\rho$ 只有 3 個；基態密度和基態波函數資訊一樣多 | 限制 :: 非簡併基態；只保證泛函存在、沒給形式〔first Hohenberg-Kohn theorem〕
