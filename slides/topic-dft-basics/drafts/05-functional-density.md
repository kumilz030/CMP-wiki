# Two Tools: Functional and Electron Density
> functional 把一個函數對應到一個數；electron density $\rho(\vec r)$ 是位置的函數〔functional〕〔electron density〕

| | function | functional |
|---|---|---|
| 對應 | $f:\mathbb R\to\mathbb R:\ x\mapsto f(x)$ | $F:\mathcal F\to\mathbb C:\ f\mapsto F[f]$〔functional〕 |
| 例子 | — | $F[f]=f(0)$〔functional〕 |

grid: 泛函導數 :: $F_v[\rho]=\int\rho(\vec r)\,v(\vec r)\,d\vec r$ 的導數 $\frac{\delta F_v[\rho]}{\delta\rho}=v(\vec r)$ | 電子密度 :: 在 $\vec r$ 找到任一電子的機率 | Kohn-Sham 形式 :: $\rho(\vec r)=\sum_{i=1}^{N}\phi_i^*(\vec r)\,\phi_i(\vec r)$〔functional〕〔electron density〕
