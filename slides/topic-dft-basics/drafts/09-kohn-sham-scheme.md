# Kohn-Sham Scheme: Quasi-particles
> 把交互作用的多電子問題，精確地轉換成不交互作用的 quasi-particles（準粒子）問題，準粒子的密度等於真實系統的基態密度〔Kohn-Sham scheme〕

| 原本的 Schrödinger Hamiltonian | Kohn-Sham Hamiltonian |
|---|---|
| 電子的動能 | 準粒子的動能〔Kohn-Sham scheme〕 |
| 受原子核的 Coulomb 位勢作用 | 受原子核的 Coulomb 位勢作用〔Kohn-Sham scheme〕 |
| 電子之間的 Coulomb 作用 | 和其他所有準粒子的平均靜態分布作用（Hartree）〔Kohn-Sham scheme〕 |
| — | 再加上一個「神秘的」exchange-correlation potential〔Kohn-Sham scheme〕 |

- 數學簡單得多，但必須知道 $V_{xc}$〔Kohn-Sham scheme〕
- 行星類比：把行星之間的交互作用關掉，加一個精心選擇的外加靜態場，就能重現每顆行星的精確運動〔Kohn-Sham scheme〕
