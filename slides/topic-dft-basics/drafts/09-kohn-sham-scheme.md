# Kohn-Sham Scheme: Quasi-particles
> 精確地換成不交互作用的 quasi-particles（準粒子），密度等於真實系統的基態密度〔Kohn-Sham scheme〕

| 原本的 Hamiltonian | Kohn-Sham Hamiltonian |
|---|---|
| 電子的動能 | 準粒子的動能〔Kohn-Sham scheme〕 |
| 原子核的 Coulomb 位勢 | 原子核的 Coulomb 位勢〔Kohn-Sham scheme〕 |
| 電子之間的 Coulomb 作用 | 和所有準粒子的平均靜態分布作用（Hartree）〔Kohn-Sham scheme〕 |
| — | 「神秘的」exchange-correlation potential〔Kohn-Sham scheme〕 |

- 數學簡單得多，但必須知道 $V_{xc}$〔Kohn-Sham scheme〕
